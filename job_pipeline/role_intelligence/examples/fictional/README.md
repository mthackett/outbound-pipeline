# Fictional example

This directory is a fully synthetic example for demonstrating the Candidate Cockpit pipeline. The candidate, company, job, metrics, and outcomes are fictional and should not be treated as real-world claims.

Files show each stage:

1. `source_bundle_raw.json`
2. `source_bundle_tagged.json`
3. `value_match_strategy.json`
4. `cockpit_content.json`
5. `example_candidate_cockpit.docx`
6. `example_candidate_cockpit.manifest.json`
